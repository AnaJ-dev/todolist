# To-Do List

A browser to-do list built with vanilla JavaScript and bundled with webpack.

## Features

- Add a to-do with a title, description, due date and priority
- Validation so empty to-dos can't be added
- Edit and delete existing to-dos
- Mark a to-do as done
- To-dos are sorted by priority, then by title
- Saved in the browser so they stay after a refresh

## Tech stack

- Vanilla JavaScript (ES modules, DOM manipulation)
- webpack (separate dev and production configs)
- ESLint
- HTML and CSS

## Running it locally

```
git clone https://github.com/AnaJ-dev/todolist.git
cd todolist
npm install
npm start
```

## What I practised

Splitting code into modules, bundling with webpack, rendering a list from data, and saving state in the browser.
